The Saturday World — a one-image broadsheet summing up Saturday 21 November 2026's world news: COP31 running into Saturday with no deal in Antalya, the double-tap strike on Kryvyi Rih, and Wall Street's worst week since 2020 — plus 12 more story cards, 27 briefs, an hourly timeline, a markets box and a dotted world map with numbered pins. 42 stories in all. Every figure was re-verified against wire reporting (Reuters, AP, AFP, BBC, CNN, WSJ, Consilium, IMD, Cricinfo) on 21 November 2026 before drawing; stories whose numbers could not be verified were dropped. `main.py` copies `entry.png` to the output directory; `draw.py` is the generator that drew the image from scratch (Pillow, DejaVu Sans); run `python3 draw.py entry.png` to reproduce it byte for byte.

## Run it

```sh
python3 main.py
```
